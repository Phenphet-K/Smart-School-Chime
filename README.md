# Smart School Chime

ระบบกริ่งและประกาศโรงเรียนสำหรับ Windows พัฒนาด้วย Python/Tkinter และ SQLite รองรับเสียงไทย/อังกฤษ ตารางรายวัน คีย์ลัด และการเชื่อมต่อ NVDA Controller API

## เริ่มใช้งานจาก source

ต้องมี Python 3.11 แบบ 64-bit บน Windows

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

`run.bat` ใช้ Python ใน PATH และเปลี่ยน working directory ไปที่โฟลเดอร์โปรแกรมให้อัตโนมัติ ต้องติดตั้ง dependencies ไว้ใน Python ที่เลือกใช้งานก่อน

## เวลาและการเล่นเสียง

- มีตารางเริ่มต้น 14 คาบ และพื้นที่ 24 คาบต่อวัน ทั้งโหมดทุกวันและแยกรายวัน
- เปลี่ยนคาบหรือการตั้งค่าแล้วต้องบันทึกก่อนนำไปใช้
- รับเหตุการณ์ที่ช้าได้ไม่เกิน 15 วินาที เมื่อกลับจาก sleep จะไม่ไล่เล่นคาบเก่าทั้งหมด
- บันทึก occurrence ใน SQLite เพื่อป้องกันคาบเดิมเล่นซ้ำหลังรีสตาร์ตหรือปรับเวลา รายการที่ล้มเหลว/ถูกยกเลิกไม่เล่นซ้ำอัตโนมัติ
- ตารางที่เวลาเดียวกันจะเข้าคิวตามหมายเลขคาบ เสียงประกาศจะรอท้ายคิว การทดสอบเสียงแทนที่คิวเดิม
- Esc ยกเลิกเสียงปัจจุบันและคิว รวมถึงประกาศที่รอส่งเข้าหน้าจอ
- ไฟล์ WAV แบบ PCM และ float ของคลังเดิมรองรับผ่านการแปลงชั่วคราว โดยไม่แก้ไฟล์ต้นฉบับ
- หากถึงเวลาปิดเครื่องขณะมีเสียงหรือคิว ระบบข้ามการปิดเครื่องรอบนั้น มีคำสั่งยกเลิก countdown ในเมนูตั้งค่า

## มือถือ: อัดแล้วส่งประกาศ

ฟังก์ชันนี้อัดเสียงในมือถือแล้วส่งเมื่อปล่อยปุ่มหรือแตะหยุด **ไม่ใช่การถ่ายทอดสดแบบ WebRTC**

1. ต่อมือถือและคอมพิวเตอร์เข้าเครือข่ายโรงเรียนเดียวกัน
2. เปิดหน้าประกาศในโปรแกรมและสแกน QR ของ HTTPS
3. ต้องให้มือถือเชื่อถือ certificate และอนุญาตไมโครโฟนก่อนใช้งาน Certificate ที่โปรแกรมสร้างเป็น self-signed มี SAN ของ IP แต่ไม่ได้ทำให้มือถือเชื่อถืออัตโนมัติ หากโรงเรียนมีระบบจัดการ certificate ควรติดตั้งตามนโยบายเครือข่าย
4. กดค้างเพื่ออัด ปล่อยเพื่อส่ง หรือใช้โหมดแตะเปิด/ปิด จำกัด 90 วินาที
5. ข้อความรับเข้าคิวหมายถึงรับไฟล์สำเร็จ ตรวจผลการเล่นจริงได้ที่ประวัติบนคอมพิวเตอร์

QR มี token ลับซึ่งหมดอายุใน 8 ชั่วโมงหรือเมื่อปิดโปรแกรม ไม่ควรเผยแพร่ URL/ภาพ QR ต่อบุคคลที่ไม่มีสิทธิ์ กด “ออก QR ใหม่ / ยกเลิกสิทธิ์มือถือเดิม” เพื่อเพิกถอน token เดิมแล้วจับคู่ใหม่

รับเฉพาะ HTTPS และ PCM WAV 16-bit, 8–48 kHz, mono/stereo จำกัด 18 MiB ต่อไฟล์ รับประกาศค้างได้ครั้งละหนึ่งงาน ตรวจ Origin และไม่เปิด CORS ข้ามเว็บไซต์ HTTP มีไว้เปิดหน้าคำแนะนำ ไม่อนุญาตอัปโหลดเสียง พอร์ตเริ่มต้น 5000/5443 สถานะ HTTPS ที่เปิดไม่สำเร็จแสดงในหน้าประกาศ

การลดเสียงรบกวนขึ้นอยู่กับเบราว์เซอร์และอุปกรณ์ ไม่รับประกันคุณภาพเท่ากันทุกเครื่อง

## ที่เก็บข้อมูล

- รัน source: `Config/settings.json`, `data/school_time.db` ในโฟลเดอร์โปรเจกต์
- รัน EXE: `%LOCALAPPDATA%\SmartSchoolChime\Config` และ `data` เก็บถาวรแยกจาก Program Files และโฟลเดอร์แตก onefile
- Log หมุนเวียนใน `logs/chime.log` สูงสุด 3 ไฟล์สำรอง ไฟล์ละประมาณ 2 MB
- ย้ายข้อมูลจาก Config/data ข้าง EXE รุ่นเดิมเมื่อยังไม่มีข้อมูลผู้ใช้ โดยไม่เขียนทับข้อมูลที่มีอยู่
- กำหนด `CHIME_HOME` เพื่อใช้โฟลเดอร์ข้อมูลอื่นได้ เหมาะกับการทดสอบหรือจัดเตรียมเครื่อง ต้องมีสิทธิ์เขียนในโฟลเดอร์นั้น
- บัญชี Windows คนละบัญชีมีข้อมูลแยกกันตาม LocalAppData

## สำรองและกู้คืน

ไฟล์สำรองรุ่นใหม่เป็น JSON `version: 1` รวมตารางครบ 192 slot และ settings ตรวจความถูกต้องทั้งหมดก่อนเขียนข้อมูล รายการซ้ำ เวลาไม่ถูกต้อง หรือโครงสร้างไม่ครบจะถูกปฏิเสธ

ยังรับไฟล์เก่าที่เป็น array ได้ โดย merge เฉพาะวัน/slot ที่ระบุ ไม่ลบ slot อื่น ควรส่งออกสำรองก่อนนำเข้าทุกครั้ง การสำรองไม่รวมไฟล์เสียงที่ผู้ใช้เพิ่มเองหรือ private key ของ certificate การกู้คืนข้าม SQLite/JSON ไม่ใช่ distributed transaction ที่ทนต่อไฟดับทุกจุด

## คีย์ลัดและ NVDA

- Ctrl+S บันทึกตาราง, Ctrl+T ทดสอบคาบที่โฟกัส
- Esc หยุดและล้างคิวเสียง
- Alt+1 ถึง Alt+8 เลือกวันตามที่แสดงในโปรแกรม
- F5 อ่านสรุป, F1 คู่มือคีย์ลัด

ใช้ NVDA Controller DLL ตาม architecture ที่ถูกต้องจากแหล่งทางการ การส่งเสียงผ่าน API ไม่ได้ยืนยันว่า widget ทุกตัวรองรับ screen reader ครบถ้วน ต้องทดสอบ NVDA จริงก่อนใช้งานในสถานศึกษา

## ระบบตรวจสอบและอัปเดตอัตโนมัติ (Auto-Updater)

- ตรวจสอบเวอร์ชันล่าสุดจาก GitHub Releases API (`Phenphet-K/Smart-School-Chime`) อัตโนมัติในพื้นหลัง 4 วินาทีหลังเปิดโปรแกรม
- เมนู `ช่วยเหลือ (Help)` -> `🔄 ตรวจสอบการอัปเดต...` สำหรับสั่งตรวจสอบด้วยตนเองได้ทุกเมื่อ
- เมื่อพบเวอร์ชันใหม่ ระบบจะแสดงหน้าต่างพร้อม Release Notes รายละเอียดการปรับปรุง และถามความยินยอมก่อนดาวน์โหลด
- หน้าต่างดาวน์โหลดแสดงความคืบหน้า (Progress Bar, % ความคืบหน้า, ขนาดไฟล์ และความเร็วในการดาวน์โหลด) พร้อมรองรับโปรแกรมอ่านจอภาพ NVDA
- เมื่อดาวน์โหลดเสร็จสมบูรณ์ ระบบจะปิดโปรแกรมเดิมอย่างปลอดภัย (เคลียร์คิว ปล่อย Mutex Single-Instance) และสั่งรันตัวติดตั้งเวอร์ชันใหม่ขึ้นมาอัปเดตทับไฟล์เดิมทันที

## ทดสอบ

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

หรือ `python audit_checks.py` ชุดทดสอบใช้ DB ชั่วคราว จำลองลำโพงและ shutdown และเปิด HTTP/HTTPS เฉพาะ loopback ด้วยพอร์ตว่าง มี GUI smoke tests บน Windows ไม่แตะฐานข้อมูลใช้งานเดิม

ตรวจการติดตั้งโดยไม่เปิด GUI/ลำโพง/server:

```powershell
.\dist\SmartSchoolChime.exe --diagnose .\diagnostics.json
```

คำสั่งนี้สร้างหรือเปิดข้อมูลในตำแหน่ง runtime ของโปรแกรม สำหรับทดสอบแบบแยกข้อมูลให้ตั้ง `CHIME_HOME` ไปยังโฟลเดอร์ชั่วคราวก่อน

## สร้าง EXE และ installer

```powershell
python -m PyInstaller --noconfirm SmartSchoolChime.spec
```

หรือ `build_exe.bat` ได้ `dist/SmartSchoolChime.exe` ซึ่งฝังเสียงทั้งหมด และชุด staging ใน `dist/SmartSchoolChime` ไม่แพ็กฐานข้อมูลใช้งานจริง การตั้งค่าผู้ใช้ หรือ certificate/private key

สร้าง installer ด้วย Inno Setup 6 จาก `SmartSchoolChime_Setup.iss` ได้ `dist/SmartSchoolChime_Setup_v1.0.1.exe` ตัวเลือก firewall จำกัด TCP 5000/5443 เฉพาะ Private profile และ local subnet
