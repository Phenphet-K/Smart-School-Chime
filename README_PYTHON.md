# 🔔 Smart School Chime (Universal Accessibility Edition)

**ระบบเสียงสัญญาณเตือนเวลาและประกาศโรงเรียนอัจฉริยะ** (Automated School Bell & Announcement System)
พัฒนาใหม่ด้วย **Python 3** ออกแบบตามหลัก Universal Design สบายตา ใช้งานง่าย รองรับการนำทางด้วยคีย์บอร์ดและโปรแกรมอ่านจอภาพ **NVDA** อย่างสมบูรณ์ 100%

---

## 🌟 จุดเด่นของเวอร์ชันใหม่

1. **♿ รองรับโปรแกรมอ่านจอภาพ NVDA เต็มรูปแบบ (Screen Reader First):**
   - เชื่อมต่อกับ `nvdaControllerClient64.dll` โดยตรง ส่งเสียงแจ้งเตือนสถานะเมื่อสลับวัน บันทึกตาราง หรือเล่นเสียง
   - มี **Menu Bar มาตรฐาน Windows** (`Alt+F`, `Alt+D`, `Alt+A`, `Alt+O`, `Alt+H`) ที่ NVDA อ่านออกเสียงได้แม่นยำ
   - กล่องกาเครื่องหมาย (Checkbox) ทุกช่องในทั้ง 24 คาบ มีชื่อกำกับชัดเจน (กริ่งเริ่ม, ขานเวลา, เปิดกิจกรรม, กริ่งเลิก) ไม่ใช่กล่องเปล่า
   - ระบบ **Auto-Scroll อัจฉริยะ**: เมื่อกดปุ่ม `Tab` เลื่อนดูคาบเรียน หน้าจอจะเลื่อนตามตำแหน่งโฟกัสอัตโนมัติ
   - คีย์ลัดด่วนครบถ้วน:
     - `Alt + 1` ถึง `Alt + 8` : เลือกตารางวัน (ทุกวัน หรือ จันทร์ - อาทิตย์)
     - `Ctrl + S` : บันทึกตารางเวลาปัจจุบัน
     - `Ctrl + T` : สั่งเล่นทดสอบเสียงในคาบที่กำลังเลือก
     - `Ctrl + R` : คืนค่าตารางเวลามาตรฐานโรงเรียน (14 คาบครบชุด)
     - `Esc` : หยุดเล่นเสียงทันที
     - `F5` : ให้ NVDA อ่านสรุปเวลาและเสียงถัดไป
     - `F1` : หน้าต่างแนะนำคีย์ลัดสำหรับ NVDA

2. **👁️ ดีไซน์สบายตา อักษรอ่านง่าย (Eye-Friendly & Ergonomic Theme):**
   - โทนสี Slate นุ่มนวล (#f8fafc) ป้องกันแสงสะท้อนจ้า ลดความเมื่อยล้าสายตาของครูและบุคลากร
   - แถบหัวเรื่องสี Dark Slate (#1e293b) พร้อมนาฬิกาดิจิทัลคมชัดสูงสีฟ้านวล (#38bdf8) และแถบแจ้งนับถอยหลังสีครีมทอง (#fef08a)
   - ขยายเต็มจออัตโนมัติ (**Maximized by default**) สะดวก มองเห็นตารางได้อย่างเต็มตา
   - ใช้สัญลักษณ์ไอคอนที่ชัดเจน สื่อความหมายทุกจุด ไร้รูปภาพโลโก้เก่าที่ไม่จำเป็น

3. **🕒 ตารางเวลาและเสียงเริ่มต้น 14 คาบเรียนมาตรฐาน (Ready to Use):**
   - มีตารางเรียนมาตรฐานโรงเรียนไทย 14 คาบเรียนพร้อมเสียงจริง บรรจุไว้ในระบบตั้งแต่เริ่มต้น:
     - **08:00** : กริ่งเริ่ม + ขานเวลา + กิจกรรมหน้าเสาธง (`เพลงชาติไทย.wav`)
     - **08:30** : กริ่งเริ่ม + ขานเวลา + กิจกรรมเข้าห้องเรียน (`ได้เวลาเข้าห้องเรียน.wav`)
     - **09:20** : กริ่งเริ่ม + ขานเวลา + หมดคาบ 1 (`หมดเวลาเรียนคาบที่1.wav`)
     - **10:10** : กริ่งเริ่ม + ขานเวลา + หมดคาบ 2 พักเบรก 10 นาที (`หมดเวลาเรียนคาบที่2พัก10นาที.wav`)
     - **10:20** : กริ่งเริ่ม + ขานเวลา + หมดเวลาพัก เข้าเรียนคาบ 3 (`ได้เวลาเข้าห้องเรียน.wav`)
     - **11:10** : กริ่งเริ่ม + ขานเวลา + หมดคาบ 3 (`หมดเวลาเรียนคาบที่3.wav`)
     - **12:00** : กริ่งเริ่ม + ขานเวลา + พักรับประทานอาหารกลางวัน (`หมดเวลาเรียนคาบที่4ได้เวลาพักรับประทานอาหารกลางวัน.wav`)
     - **12:50** : กริ่งเริ่ม + ขานเวลา + เตือนเข้าเรียนภาคบ่าย (`ได้เวลาเข้าห้องเรียน.wav`)
     - **13:00** : กริ่งเริ่ม + ขานเวลา + เริ่มเรียนคาบ 5
     - **13:50** : กริ่งเริ่ม + ขานเวลา + หมดคาบ 5 (`หมดเวลาเรียนคาบที่5.wav`)
     - **14:40** : กริ่งเริ่ม + ขานเวลา + หมดคาบ 6 (`หมดเวลาเรียนคาบที่6.wav`)
     - **15:30** : กริ่งเริ่ม + ขานเวลา + เลิกเรียน/มาร์ช (`หมดเวลาเรียนคาบที่7ต่อด้วยมาร์ช.wav`) + กริ่งเลิก
     - **15:40** : กริ่งเริ่ม + ขานเวลา + ทำความสะอาดพื้นที่ (`ได้เวลาทำความสะอาดเขตพื้นที่รับผิดชอบ.wav`)
     - **16:30** : ขานเวลาเลิกงาน + กริ่งเลิก
   - สามารถกด `Ctrl + R` หรือปุ่ม *"🔄 ค่าเริ่มต้นโรงเรียน"* เพื่อคืนค่าตารางนี้ได้ทุกเมื่อ

4. **📂 จัดระเบียบโฟลเดอร์เป็นสัดส่วน ชัดเจน:**
   - `/config` : เก็บไฟล์ตั้งค่าระบบ `settings.json`
   - `/data` : เก็บฐานข้อมูลเวลา `school_time.db` และไฟล์ข้อมูลสำรอง
   - `/sound` : เก็บไฟล์เสียงทั้งหมด (กริ่ง, ขานเวลา, ประกาศกิจกรรม)
   - `/legacy` : รวบรวมไฟล์โปรแกรมเก่า VB.NET เดิมและตัวติดตั้ง Access Database Engine

## 🚀 วิธีการเปิดใช้งาน

### วิธีที่ 1: รันด้วย Python โดยตรง
ดับเบิลคลิกที่ไฟล์:
```
run.bat
```
หรือรันคำสั่ง:
```bash
python main.py
```

### วิธีที่ 2: คอมไพล์เป็นไฟล์ `.exe` สำหรับแจกจ่าย
ดับเบิลคลิกที่ไฟล์:
```
build_exe.bat
```
ไฟล์ EXE จะถูกสร้างไว้ที่โฟลเดอร์ `dist/SmartSchoolChime.exe` พร้อมนำไปติดตั้งหรือใช้งานบนเครื่อง Windows ทั่วไปได้ทันที

## 📂 ผังโครงสร้างโฟลเดอร์โปรเจกต์

```
Smart School Chime/
│
├── main.py                     # ส่วนติดต่อผู้ใช้หลัก (GUI, Accessible Controls, Scheduler)
├── database.py                 # ระบบฐานข้อมูล SQLite ในโฟลเดอร์ /data
├── config_manager.py           # ระบบจัดการและบันทึกการตั้งค่าใน /config
├── audio_player.py             # ตัวควบคุมและเล่นไฟล์เสียง .wav ในพื้นหลัง
├── nvda_client.py              # ตัวเชื่อมต่อ API กับโปรแกรมอ่านจอภาพ NVDA
├── nvdaControllerClient64.dll  # ไลบรารี C-API สำหรับ NVDA 64-bit
├── run.bat                     # สคริปต์เปิดโปรแกรม
├── build_exe.bat               # สคริปต์คอมไพล์เป็นไฟล์ EXE
│
├── config/                     # โฟลเดอร์เก็บการตั้งค่า
│   └── settings.json           # การตั้งค่าโหมดวัน, ชุดเสียง, ปิดเครื่อง
│
├── data/                       # โฟลเดอร์เก็บฐานข้อมูล
│   ├── school_time.db          # ฐานข้อมูล SQLite (ตารางเวลา 24 คาบ x 8 วัน)
│   └── initial_schedule.json   # ข้อมูลเวลาสำรอง
│
├── sound/                      # คลังไฟล์เสียงทั้งหมด
│   ├── Bell/                   # ชุดเสียงกริ่ง (Sound01 - Sound05)
│   ├── Thai/                   # เสียงขานเวลาไทย และ ConTN (เสียงกิจกรรม)
│   └── Eng/                    # เสียงขานเวลาอังกฤษ และ ConTN
│
└── legacy/                     # ซอร์สและไฟล์ของเวอร์ชันเดิมในอดีต (VB.NET 2019)
```
